# Knap filters

Pipe graph props through a `graph_*` filter to produce Markdown. The filters
are synchronous, framework independent TypeScript. The `mdxcn-vue/knap` entry
does not load Vue. Knap belongs to the host; no Knap dependency is bundled.

## Output

These outputs are generated by the real filters at build time:

<pre data-knap="ascii"><code>{{ data.ascii }}</code></pre>

<pre data-knap="comark"><code>{{ data.comark }}</code></pre>

## Wire into a host

```ts
import { createEngine, standardFilters } from 'knap'
import { graphFilters } from 'mdxcn-vue/knap'

const engine = createEngine({ filters: { ...standardFilters, ...graphFilters } })
```

Knap is an optional host installation. Its CLI uses standard filters; register
custom filters in your application with `createEngine`. For copied sources,
install `public/r/mdxcn-graph-knap.json` through the registry and import
`./components/mdxcn/knap/graph-knap` instead.

```ts
import { createGraphFilters, graphFilterMetadata } from 'mdxcn-vue/knap'

const filters = createGraphFilters(['graph_meter', 'graph_timeline'])
// Merge graphFilterMetadata into the host's validateFilters metadata.
```

## Input and formats

`context.rawValue` takes precedence over parsed JSON. Objects become props;
arrays/scalars go into each graph's default field. `graph_table` also converts
records to headers and cells, using the first record's keys. A quoted or plain
string parameter overrides the title. `comark` selects a `::graph-*` YAML block.

```text
{{ coverage | graph_meter:"SHIPPED" }}
{{ events | graph_timeline:"comark" }}
```

Content filters (`graph_callout`, `graph_steps`, and others) accept a Markdown
string or `{ body, ...props }`. Use `body` for content; Vue slots and compiler
models are not filter input. The 46 names cover 39 ASCII drawers. Plot, Heatmap,
Activity, Calendar, Flow, Timer and Countdown emit Comark by default. Unreadable
input and thrown drawing or serialization errors report a warning through
`context.reportWarning` and return the original string. This is not schema
validation: malformed data that does not throw can silently print `undefined`,
`NaN%` or `[object Object]`, matching upstream.

Filter input may be untrusted. ASCII fences open with more backticks than any
potential closing run in the drawing, so cell text cannot close the fence early.
Comark output includes a Markdown `body`; a line containing only `::` closes its
block. The host must validate data and configure its parser and renderer for
untrusted Markdown; the filters are not a sanitizer. See [Comark](./comark).

ASCII follows upstream's independent print schema and drawing grammar. For
example, Bars uses `from` and `to`, Table uses `headers` and `rows`; runtime item
components and Vue `written`/`list` models are not interpreted. Invalid waffle
dimensions fail with a warning. Nested YAML objects and YAML-like string values
are preserved, fixing upstream serialization errors.
